# impacta-monitoring-demo
Repositório de fontes para os scripts que compõem a Demo de monitoramento

## Setup
Para executar essa DEMO é necessário instalar o Virtual Box e o Vagrant

## Execução
Comando para executar o Vagrant:
```
vagrant up
```
Para conseguir adentrar no contexto da máquina virtual criada pelo Vagrant, utilize o comando:
```
vagrant ssh
```
Se quiser parar a máquina virtual, execute o comando:
```
vagrant halt
```
